# whenfree

チームのみんなの「空いている時間」を重ねて見て，集まる日時を決めるための Web アプリです．
各自が自分の予定を入れておくと，チームの1週間の空き・埋まりが分かり，候補の日時に「はい・いいえ」で返事ができます．

## どういうアプリか

### 誰のためのアプリか

授業・バイト・サークルなどで，一人ひとりの予定がばらばらな少人数のチーム（ゼミ・グループ課題・サークルの係など）のためのアプリです．

### どんな困りごとを解決するか

- 集まる日を決めるたびに，チャットで全員に空いている時間を聞くのが手間です．
- 返事がそろうまで時間がかかり，誰がまだ返事をしていないのかも分かりにくいです．
- 前に聞いた予定が今も正しいか分からないまま，日時を決めてしまうことがあります．

### どのように解決するか

- **予定は1回入れておけば使い回せる**：毎週の予定と単発の予定を登録しておくと，毎回聞かなくても，チームの1週間の空き・埋まりが表で分かります．
- **候補に「はい・いいえ」で返事を集める**：空いていそうな日時を候補として出し，メンバーはボタンで返事をします．「あと◯人の返事待ち」が出るので，返事がそろったかすぐ分かります．
- **古い予定は「不明」と出す**：予定を7日を超えて更新していない人は，空きとも埋まりとも決めずに「不明」と出します．ホームでも予定の確認を促すので，古い予定のまま決めてしまうのを防ぎます．

## できること

- **自分の予定**：毎週の予定（授業・バイトなど）と，単発の予定を登録・編集・削除できます．
- **チーム**：チームを作り，招待コードを伝えてメンバーに参加してもらえます．
- **チームの1週間**：メンバー全員の予定を重ねて，枠ごとに「空き」「埋まり」「不明」を出します．（画面は準備中です）
- **候補と返事**：集まりたい日時を候補として出し，メンバーが「はい・いいえ」で返事をします．「あと◯人の返事待ち」が分かり，候補を作った人が確定・取り消しをします．
- **ホーム**：自分のチームと，予定を最後に更新した日を出します．しばらく更新していないときは，確認の案内が出ます．

## 使い方の流れ

1. **登録・ログイン**：`/register` を開いてアカウントを作ります．
2. **チームを作る・参加する**：「チーム」の画面で，チームを作るか，招待コードを入れて参加します．チームの画面に出る招待コードを，メンバーに伝えます．
3. **予定を入れる**：「予定」の画面で，毎週の予定と単発の予定を登録します．
4. **候補を作る**：チームの画面の「候補を見る →」から，集まりたい日時を候補として作ります．必要な人数を入れなければ，チーム全員の返事を待ちます．
5. **返事をする**：メンバーは候補に「はい」か「いいえ」で返事をします．「あと◯人の返事待ち」は10秒おきに新しくなります．
6. **確定・取り消し**：候補を作った人が，返事を見て「確定する」か「取り消す」を押します．

2つのウィンドウ（片方はシークレットウィンドウ）で別々の人としてログインすると，返事のやりとりを試しやすいです．

## 手元で動かす

### 必要なもの

- PHP 8.4.1 以上
- Composer
- Node.js（LTS版）

### はじめて動かすとき

```sh
git clone https://github.com/ka6629/whenfree.git
cd whenfree
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
npm install
npm run build
```

データベースは SQLite（`database/database.sqlite`）を使います．
`--seed` をつけると，上のデモ用のアカウントとデモチームが入ります．

### 起動する

```sh
composer run dev
```

ブラウザで http://localhost:8000 を開きます．

### データを最初の状態に戻す

```sh
php artisan migrate:fresh --seed
```

### テスト

```sh
php artisan test
```
